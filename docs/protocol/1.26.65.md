# Bedrock protokolü 1.26.65 (protocol 2225)

Bu belge, PickaxeMP'nin hedeflediği protokol sürümünü ve **doğrulanmış
kaynaklarını** tanımlar. Şemalar tahmin edilmemiştir; Mojang'ın
sürümlendirilmiş deposundan alınmıştır.

## Sürüm farkı uyarısı

`NetworkSettings` paketi **2259'da 6 alan**, **2225'te 5 alan** taşır:

| Alan | 2225 | 2259 |
|---|---|---|
| Compression Threshold (uint16) | ✅ | ✅ |
| CompressionAlgorithm (uint16) | ✅ | ✅ |
| Client Throttle Enabled (bool) | ✅ | ✅ |
| Client Throttle Threshold (uint8) | ✅ | ✅ |
| Client Throttle Scalar (float) | ✅ | ✅ |
| SCTP Recovery Profile (uint8) | ❌ | ✅ |

`ResourcePackStack` da farklıdır: 2225'te son alan `Include Editor Packs`
(bool), 2259'da `Editor Pack Types` (uint8 bit bayrakları).

Hedef 2225 olduğu için PickaxeMP 5 alanlı ve bool'lu biçimi uygular.
Sürüm yükseltilirse bu iki paket **mutlaka** yeniden kontrol edilmelidir.

## El sıkışma sırası

```
C→S  RequestNetworkSettings (193)   clientNetworkVersion int32 BE
S→C  NetworkSettings (143)          sıkıştırma eşiği + algoritma
C→S  Login (1)                      JWT zinciri
S→C  PlayStatus(LoginSuccess) + ResourcePacksInfo + ResourcePackStack
C→S  ResourcePackClientResponse(4)
S→C  (Phase 4: StartGame ...)
```

## Doğrulanmamış noktalar (dürüst liste)

Aşağıdakiler **resmî şemada açık değildir** veya gerçek istemciyle
denenmemiştir. Kod bu belirsizlikleri yorumlarda işaretler.

1. **`ResourcePackClientResponse` birleşim kodlaması.** Şema kontrol
   değerini `uint32` işaretler; alt yapıların kendi alanı `int8 + const`.
   Cereal'ın bunu bir mi iki mi kez yazdığı belgede yok. PickaxeMP tek
   `uint32` okur/yazar.
2. **`Experiments.Toggles` sayımı.** `"No size compression"` işaretli;
   PickaxeMP sabit `uint32` kullanır.
3. **NetherNet'te zarf/batch.** Paketlerin `0xFE` zarfı kullanıp
   kullanmadığı Mojang NetherNet rehberinde yazmıyor. Üçüncü taraf belge
   "batch'lenmez" der. `PacketBatch` iki strateji sunar, varsayılan `raw`.
4. **Sıkıştırma eşiğinin ölçüm birimi.** Şema "en küçük ham yük boyutu" der
   ama paket kimliğinin dahil olup olmadığı belirsiz. PickaxeMP kimlik dahil
   tam yükü ölçer.
5. **UUID bayt sırası.** `uint64` = native (LE) varsayıldı; round-trip
   testleri geçer, istemci uyumu Phase 4'te sınanmalı.

Bu maddeler **gerçek istemci testi** ile kapanmadan Phase 2 tam doğrulanmış
sayılmaz.
